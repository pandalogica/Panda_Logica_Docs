## 1. Starter packs sold at checkout

A starter pack is an optional extra line on an MBI Stripe checkout. The website will only add a pack that is active for that product and whose minimum tier is met by the tier you are buying. The purchase is stored against the business. It does not, in the current website code, change the MBI plan feature limits (`product_tier_features`).

A starter pack purchase therefore does not increase MBI plan capacity. Plan capacity remains the tier you subscribed to. The pack is a separate entitlement, identified by the pack you selected.

What you receive is the pack described in the catalogue at checkout (name and description). The application code does not define a fixed list of templates inside every pack.

If a starter pack is added to a **trial** checkout, it is a line on that same subscription. There is no separate pack-only trial in the checkout code. The 14-day trial rules in the Terms of Service apply to that subscription. We do not state that pack content keeps working after the trial if the subscription does not continue.

## 2. Accelerator content packs

An accelerator pack is content installed into MBI: a manifest that can include queries, layouts, dashboards, calculated fields, catalogue definitions and install scripts. The desktop types also include an entitlement record with a pack id, SKU, an environment limit and an updates-until date. That record is defined for a licence response. The current website licence check returns plan feature limits. It does not return those pack entitlement records.

A compatible, valid MBI licence is required to use MBI, including to import and run pack content in MBI. The pack entitlement, where one has been granted, is separate from the MBI plan’s feature limits.

Compatibility requirements that are actually on the manifest (for example an ERP family or hallmark tables) apply to that pack. We do not promise that a pack fits every ERP version.
