# MBI FAQ

_Last updated: 2026-07-13_

Short answers to questions we hear most often. For step-by-step recovery, see **[Troubleshooting Common Issues](common-issues.md)**.

## Getting started

**Do I need administrator rights to run reports?**  
No. Most business users only need a role that grants the relevant queries. Administrators configure environments, ASR, and roles.

**Where do I start after install?**  
Follow **[First Login](../getting-started/first-login.md)**, then **[Setting Up a Report](../user-guides/setting-up-a-report.md)**.

## Access and security

**Why can a colleague see reports I cannot?**  
Roles differ. Ask an admin to compare your group/role assignments — see **[Roles](../admin-guides/roles.md)**.

**Does MBI change my ERP data?**  
Normal reporting reads from the target system (TSR). Configuration changes live in ASR metadata. Prefer read-focused service accounts for connections.

## Reports and layouts

**What is the difference between Dashboard and Grid?**  
Dashboards emphasise charts and KPIs. Grids are detailed tables you can filter, group, and export. Many reports offer both.

**Can I reuse filters next time?**  
Yes — save a personal layout after setting filters and column order.

## Administration

**What is ASR vs TSR?**  
ASR is metadata (tables, fields, joins, queries). TSR is the live database. See **[ASR Setup](../admin-guides/asr-setup.md)** and **[TSR Setup](../admin-guides/tsr-setup.md)**.

**How do I add a calculated margin field?**  
See **[Creating Calculated Fields](../advanced/calculated-fields.md)**.
