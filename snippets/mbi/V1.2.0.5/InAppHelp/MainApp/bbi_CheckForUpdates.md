# Check for Updates

The ribbon shows your installed MBI version and the available version. When a newer version is available, click the update status or choose Check for Updates to see both versions.

For an individual PC, a Windows administrator can choose to install. Save your work first. Windows may request administrator permission; cancelling leaves MBI open. After approval, MBI closes for the update and reopens. If it does not reopen, use your usual shortcut. Users who are not Windows administrators should contact their administrator.

For a shared installation, the administrator arranges the update. MBI does not offer individual installation; the configured contact is notified according to the shared-installation policy.

If you are upgrading an older updater that cannot write to Program Files, obtain the complete current MBI installer and run it with Windows administrator permission.
