# Composite report maintenance

To include a sub report in a Composite report, drag it from the available list on the right to the included list on the left. To remove one, drag it back to the right. Changes are saved immediately.

Close and reopen maintenance to review the saved selection. Each included sub report needs a distinct name; rename conflicting reports before adding them. If saving fails, MBI shows an error and keeps the failed item in its original list. Earlier successful changes remain saved.
