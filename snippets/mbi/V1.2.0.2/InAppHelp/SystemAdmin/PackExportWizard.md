# Export an accelerator pack

Choose the categories, queries, dashboards and grid layouts to include. A checkbox on each Dashboards or Grid Layouts heading selects or clears that document type for the query; a mixed state means only some children are selected.

Export includes the linked reports and metadata required by the selected content. Supporting reports can be hidden from the main report menu while still serving a Header/Detail tab. Distribute one complete versioned download; the recipient should not need another pack.
