# Application Updates

Choose who installs updates, then save. You must be an MBI system administrator to change these settings.

## System administrator (shared installation)

Use this for a shared installation. Enter the update contact email. The administrator arranges installation for everyone; MBI does not offer each user an individual update. Send test email checks the configured contact route.

## User (individual PC)

Use this for a separate installation on one PC. MBI shows installed and available versions. Click the update status to review the update. A Windows administrator can install and approve Windows elevation; other users are told to contact their administrator. Being an MBI system administrator alone does not grant Windows permissions.

Settings are stored in ProgramData, separately for each MBI installation, so saving does not require writing to Program Files. An existing installation-local policy is retained until the new settings are saved.

To repair an older updater, run the complete current MBI installer with Windows administrator permission. Keep the existing installation location.
