# Check for Updates

MBI checks for a new release when you open Viewer. To check again, open the options menu at the top right and select **Check for Updates**. The result shows your installed version and the published version.

## Updating an individual PC

When a newer release is available, MBI lists the files it needs to update. Save your work before choosing **Yes**. MBI downloads and verifies the changed files, closes Viewer, installs them and reopens Viewer. PandaAppUpdater can update itself in the same operation. Choose **No** to keep working. You can run the check again later.

Your Windows account needs write access to the MBI installation folder. If an install reports that a program is using a file, close the other MBI program using that installation and try again.

## Using MBI on a shared PC or server

Your system administrator installs updates for everyone using that copy of MBI. A check can notify the configured update contact once per release. If no contact is configured, the manual check asks you to contact your system administrator.
